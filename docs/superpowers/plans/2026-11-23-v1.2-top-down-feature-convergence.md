# 高层引擎闭环架构收敛 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将已落地的 OpenTelemetry 2.0 AI 追踪、去中心化 Multi-Agent 工作窃取网格、以及 WebAssembly (WAMR) 沙箱插件三大能力深度缝合入主请求生命周期 (`csilk_app_t` / `csilk_ctx_t`) 与工作流调度引擎 (`csilk_wf_t`)。

**Architecture:** 采用解耦式上下文注入与句柄挂接模式，在 `csilk_wf_t` 内部挂接 `csilk_wf_grid_t` 提供统一网格切片调度；在 `csilk_app_t` 封装 `csilk_app_use_wasm` 拦截中间件与工作流 WASM 工具节点；在 `csilk_ai_*` 驱动层提供上下文感知 API `csilk_ai_chat_ctx` / `csilk_ai_stream_ctx`，内部自动完成 OTLP 侧车指标关联。

**Tech Stack:** C23 (`CMAKE_C_STANDARD 23`), WAMR 2.4.4, libuv, POSIX, OpenTelemetry Trace W3C.

**Spec:** `docs/superpowers/specs/2026-11-23-v1.2-top-down-feature-convergence-design.md`

## Global Constraints

- 严格保持 SOVERSION 1 纯净公共符号命名 (`csilk_*`)，零 baseline 丢失；
- 保持所有 `#include` 与 `static` 变量声明置于文件顶部声明块；
- 遵循 LLVM 18 `clang-format` 规范，`check-format` 零差异；
- 遵循 Conventional Commits with Emoji (`type(scope): 🎯 subject`)。

## Review Focus

1. `csilk_wf_set_grid` 与 `csilk_wf_free`: 工作流释放时确保不产生针对外部 grid 的 double-free 或野指针；
2. `csilk_app_use_wasm`: 当 plugin 未初始化或中间件池满时优雅返回 -1，不导致段错误；
3. `csilk_ai_chat_ctx`: 当 `ctx == NULL` 时优雅降级为常规推断，不引发空指针解引用；
4. `csilk_wf_submit_grid_task`: 当 workflow 尚未挂接 grid 时返回错误码，不崩溃；
5. `csilk_wf_add_wasm_plugin_node`: 多次并发执行节点时，沙箱线性内存与 fuel 预算相互隔离。
