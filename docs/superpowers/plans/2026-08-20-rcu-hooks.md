# RCU & Copy-On-Write Lifecycle Hook System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Refactor `src/core/config/hooks.c` to use immutable contiguous handler arrays, Copy-On-Write (CoW) updates, and RCU / Epoch-based safe memory reclamation.

**Architecture:** `struct csilk_server_s` holds `_Atomic(csilk_hook_array_t*) hooks[CSILK_HOOK_COUNT]`. Readers in request hot path read the pointer atomically with $O(N)$ contiguous cache-friendly execution (0 mutexes, 0 malloc). Writers use CoW guarded by `s->hook_mutex`, publish atomically, and wait for reader grace period (`csilk_server_wait_grace_period(s)`) before freeing retired arrays.

**Tech Stack:** C23, C11 stdatomic, ThreadSanitizer, AddressSanitizer, CMake, CTest.
