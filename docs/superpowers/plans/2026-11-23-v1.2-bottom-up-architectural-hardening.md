# 自底向上架构硬化与遗留收敛 (Bottom-Up Architectural Hardening) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现线程安全加固（消除 strtok）、SSRF 防御引擎、三组件原子热更新统一执行器与空闲连接 Arena 延迟分配优化，全面达成底层性能与安全生产级硬化。

**Architecture:** 
1. 安全加固：升级 `llama.c` 分词为 `strtok_r`；在 `src/core/primitives/ssrf.c` 构建 CIDR IPv4/IPv6 私网与云元数据过滤引擎，暴露 `csilk_security_*` API。
2. 三组件热更新：在 `server_rcu.c` 扩展 `csilk_hot_update`，在持有 `config_mutex` 下原子更新 Router、WASM 句柄和 Config，并单调递增 RCU epoch 接入 EBR 宽限期。
3. 连接池内存优化：在 `connection_io.c` 和 `connection_close.c` 实现 Arena 延迟获取与空闲 Keep-Alive 归还机制，极度缩减 10K 连接 RSS。

**Tech Stack:** C23, libuv/io_uring, POSIX sockets (`inet_pton`), RCU/EBR, LLVM 18 clang-format, CMake.

**Spec:** `docs/superpowers/specs/2026-11-23-v1.2-bottom-up-architectural-hardening-design.md`

## Global Constraints

- **Language Floor**: C23 (`CMAKE_C_STANDARD 23`), built-in `nullptr`, `bool`.
- **SOVERSION 1 Stability**: 保持公共符号导出 100% 具备 `csilk_*` 前缀，基线符号 0 丢失。
- **Formatting**: 100% 符合 LLVM 18 `clang-format`，通过 `cmake --build build --target check-format` 门禁。
- **Declaration Placement**: 所有 `#include` 与静态变量置顶，严禁置于函数体之间。

## Review Focus

1. **IPv4-Mapped IPv6 绕过**: 类似 `::ffff:127.0.0.1` 或 `::ffff:169.254.169.254` 必须被正确解包并识别为私网地址。
2. **Cloud Metadata Link-Local 拦截**: `169.254.169.254` 必须被严格识别拦截，防止云上 IAM Token 泄漏。
3. **Partial Hot-Update**: `csilk_hot_update` 传入任意子集（如只更新 router 或只更新 wasm/config）时，均能安全原子更新，且不更新的组件保持不变。
4. **Keep-Alive 状态切换时 Arena 悬空指针**: 空闲归还 Arena 后，必须确保 `ctx.arena = NULL`，且下次请求到达时必须自动重新分配，严禁出现空指针解引用。
5. **并发 RCU 宽限期回收安全性**: 三组件同时退休时，EBR 链表必须正确承载并安全释放旧资源。
